# ADR-0006 稳定收款账户与证据历史

2026-10-16，#15实施决策。receiver代表稳定的环境/平台/登记账户，设备授权以独立binding代次保存，channel只是账户别名；不能把换设备或改channel当作新收款账户，否则迟到付款保护和历史证据会被重置。代号由运营登记，并不证明真实账户唯一，真实准入仍受#8约束。

观察器表采用带摘要的版本化PostgreSQL SQL，而不是让ORM自动推断复杂复合外键、部分唯一索引和不可变历史trigger。这样能对首次迁移、重复运行和失败回滚给出确定验收；代价是后续变更必须新增迁移版本，不能直接改已应用脚本，也没有自动删除历史的down迁移。旧业务表继续使用原有迁移机制，本批不声称整个旧AutoMigrate链路都原子化。
