# ADR-0002 模拟器优先与证据分层

状态：Accepted for planning scope。依据：用户明确要求“先用安卓模拟器”。实现技术仍待评审。

决定：先使用 AVD 与独立合成通知夹具验证系统回调、解析、队列、上报和 New API 测试充值闭环。模拟构建／凭据／环境明确隔离，不能冒充真实来源。

真实 App 在模拟器中的安装、登录和通知投递是探索事项，不作为夹具测试前置阻塞；失败如实记录。真机验证保留为后续里程碑，未验证不得宣称支持实际收款。

验收报告使用四个层次：纯样本、模拟器夹具、模拟器真实 App、实体真机。禁止只写“Android 测试通过”而省略层次。
