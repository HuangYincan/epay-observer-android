## 结果

用户重新确认登录后，自行点击本地页开始并安排一条普通支付宝消息。120秒窗口从0增加到2次固定支付宝来源回调，最终EXPIRED；各次采样的来源匹配、监听连接、屏幕交互及未锁定条件均符合预期，清理和原四笔账务审计通过。本次 **notification_delivery=Observed**，是模拟器真实App的单次通知回调可达证据。

2次回调不等于2条独立消息或付款。探针没有读取通知正文、标识、账号或金额，无法把某个回调与这条消息一一对应，也不能由此确认收款、解析、订单归属或New API真实自动充值。登录及发送均为用户反馈，不是平台会话或发送时间的独立测量。

## 环境及操作

沿用唯一专用`Medium_Phone_API_37.0` / `emulator-5554`，API37 / Android17 / arm64，支付宝12.12.30.8000 / 212310。原无窗口实例正常退出后，以同一userdata、端口、4核/4GiB/SwiftShader、不加载或保存快照恢复带窗口模式；未清数据、重建AVD或启动第二实例。恢复前后原四笔审计不变，恢复本任务reverse。macOS辅助访问被拒，桌面控制查询窗口又被自动审批拒绝，未自动确认原生窗口位置；随后只用ADB确认探针前台组件，未读取支付宝或通知界面。

用户找不到控制入口时，代理将既有私有本地链接交给默认浏览器打开；网页等待不采集。代理只打开普通支付宝入口供用户自行登录，随后打开探针置支付宝于后台，不读取登录页、聊天页或弹窗，不代填账号、验证码或代发消息。

实际条件为探针前台、屏幕亮起、keyguard未锁定，系统锁屏仍disabled=true。驱动约每秒复核条件，在计数变化或每10轮采样时输出聚合状态；不能排除两个检查点之间的短暂变化。instrumentation影响进程优先级；这不是自然后台回收、长期可靠性、真正锁屏或真机测试。未重跑已完成生命周期矩阵或合成充值。
