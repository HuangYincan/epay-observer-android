# 安卓模拟器优先测试计划

状态：Not run。设备、镜像与工具均未安装或选定，本轮不执行这些步骤。

## 测试层次

| 层次 | 证明什么 | 不能证明什么 |
| --- | --- | --- |
| JVM／纯解析单测 | 给定样本的规范化与解析结果 | 系统通知投递和真实文案 |
| AVD + 夹具 App | 权限、服务回调、持久队列、上报、生命周期 | 真实微信／支付宝的通知格式与可投递性 |
| AVD + 真实支付 App（若可行） | 该镜像与应用版本组合下的行为 | 所有手机或正式收款稳定性 |
| 实体真机 | 指定设备与 App 版本的真实到账行为 | 其他 OEM 和未来版本 |

## 环境计划

优先一个开发 AVD，建议再加入另一 Android API 镜像测试；API 35／36 只是待工具链核对的候选，不是已测试兼容范围。宿主架构为 Apple Silicon 时选择受支持镜像，不将 ARM 与 x86 差异忽略。

测试拓扑：Observer test build + fixture app → HTTPS 测试网关 → 测试 PostgreSQL → New API 测试实例。使用受信任测试 CA 或受控 HTTPS 入口；Release 不得包含明文或忽略证书开关。主机到 AVD 的地址映射必须在实施文档明确。

## 场景清单

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| EMU-01 | 微信形态合成收款，唯一订单 | 完整自动充值一次 |
| EMU-02 | 支付宝形态合成收款，唯一订单 | 完整自动充值一次 |

| EMU-08 | 同金额两单、跨 receiver／provider | 不串单，输出明确冲突 |
| EMU-09 | 旧付款迟到且同额新单存在 | 不误充值到新单 |
| EMU-10 | 重启、服务断连、撤权、强制停止 | 状态真实、持久队列可恢复；不声称补回漏投通知 |
| EMU-11 | 设备撤销、body 篡改、旧封套 | 拒绝且无账务变化 |
| EMU-12 | 商户通知超时、重放、响应丢失 | 仅重试通知，New API 增额一次 |
| EMU-13 | 测试事件／测试设备发往生产配置 | 拒绝，无账务变化 |
| EMU-14 | Release 包检查 | 无夹具信任、验签旁路或调试确认入口 |
