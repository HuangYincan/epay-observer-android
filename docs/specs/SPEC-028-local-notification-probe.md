# SPEC-028 支付宝本地通知可达性探针

2026-10-17；#33 / #42；承接用户“微信没有啊，你先验证支付宝吧”。本批只验证支付宝系统通知回调可达性，不等待微信登录，不采集通知正文或付款。沿用SPEC-001/008来源边界与ADR-0002证据分层。

## 范围与实现约束

- 独立 `probe` 模块，包名 `dev.epay.observer.probe.debug`，只提供debug变体。没有对app/fixture模块的依赖、网络权限、配对、账本、ReceiptEvent、持久存储或数据导出；不改现有正式/夹具来源规则。
- 只允许D0官方来源核验得到的支付宝包 `com.eg.android.AlipayGphone`、versionCode `212310`、当前签名集合恰为 `389b49f7832f53e9017923220aa85e14dfaa4886ecd7428818bf339543cf498a`。这是本批通知来源实验固定输入，不是生产收款信任准入。版本或签名变化即停止，需重新核验。
- 内容读取前核对系统package/opPkg、当前Android用户和安装包UID。仅处理 `onNotificationPosted`；不调用 `getActiveNotifications`，不读取/保存Notification、extras、title/text、key、id/tag、channel、时间戳、账号或通知正文。无关来源直接忽略。
- 进程启动默认停止；用户在探针内显式点“开始两分钟观察”，必须先有通知读取权限、服务连接和正确来源。窗口按 `elapsedRealtime` 计时，满120秒自动停止接收计数。手工停止、断连/监听服务销毁、进程死亡、时间倒退或来源失配结束窗口；重连不自动开始。
- 仅内存保存回调次数、连接和会话状态；每次开始清零，最多500次后停止并提示。UI明确“回调次数不等于新通知/独立通知/付款次数”，系统重投或更新可能增加计数。不得据非零计数声称收款或充值成功；零计数仅表示该窗口未观察到回调，不证明来源从不通知。
- 无外部intent参数启动采集；仅界面按钮启动。系统通知访问授权单独显示，用户可到系统页面授予或撤销；结束实验建议撤销。探针不代用户发送聊天、付款或触发平台操作。

## 验收

- PROBE-01：纯JVM测试固定来源接受，错误包/opPkg/用户/UID/版本/签名均拒绝；真实应用证书不从夹具推断。
- PROBE-02：纯JVM测试默认停止、必须连接、窗口过期边界、手停、断连重连、时钟倒退、容量上限及无效来源不增加计数。
- PROBE-03：最终APK检查无uses-permission、无provider/receiver及其他service，唯一listener由BIND_NOTIFICATION_LISTENER_SERVICE保护；无备份、仅支付宝package可见、无release变体，DEX不含内容/活动通知读取或网络/存储调用。构建、单测、lint与产物检查纳入CI。
- PROBE-04：在专用AVD安装并验证权限/监听连接/起停；测试可用无关合成通知检验拒绝，但不得把它记作支付宝投递成功。实际支付宝通知需明确用户触发场景；未观察到来自支付宝的真实回调时保持Not run/Blocked，不造系统包名或绕过签名。
- PROBE-05：单独记录权限、来源校验、监听与实际支付宝回调证据；保持原四笔合成账务。真实内容字段、解析、后台长时稳定性和#8订单归属仍未验收。

## 无资金的人工步骤

安装探针，开启其通知访问权限；回到探针确认支付宝来源匹配及监听已连接。用户准备好后开始两分钟观察，把支付宝置后台，使用自己已有的受控方式触发一条非资金支付宝通知（例如由用户自行安排的测试消息）。探针只显示计数。若没有可用触发方式，记录阻塞，不代发消息、不发起付款。完成后停止并撤销探针通知权限。

## 无人操作的生命周期验证

2026-10-17用户要求代理自动测试，不再要求用户点击。自动化仅在androidTest与宿主脚本中实现，通过原界面按钮开始窗口；主APK不增加外部启动接口、存储、网络或正文访问。保留用户已报告的普通通知和锁屏正向反馈，未取证的重复轮数不补写Passed。

- AUTO-01：仅显式emulator-NNNN且ro.kernel.qemu=1；记录并恢复原Wi-Fi/移动数据、通知监听授权、屏幕状态及本任务reverse。拒绝在已有电池模拟/强制Doze或未知网络设置上叠加测试；不关闭系统验证、不增白名单、不清应用数据。
- AUTO-02：若系统启用锁屏，三轮屏幕熄灭且keyguard locked，每轮观察20秒，验证计数窗口及监听未断。若`locksettings get-disabled`为true，真正锁屏标Blocked，不改策略；改为独立命名的三轮screen_off并记录keyguard实际值，不冒充锁屏通过。网络关闭15秒后恢复原值，验证默认网络实际断开及恢复；强制Doze15秒必须由PowerManager确认进入。每轮记录来源匹配、窗口状态及实际回调数。
- AUTO-03：熄屏后台135秒后窗口必须EXPIRED；120秒以后的回调不再被计数。这仅验证隐私窗口超时，不表示长时间后台通知可靠性。
- AUTO-04：只终止探针自身进程、探针强停、支付宝强停后正常重开及AVD重启分别记录。支付宝只看进程与stopped标志，不读取账号页面、不声称重开后登录已验证。探针新进程必须默认停止且计数清零；不要求恢复旧观察窗口。
- AUTO-05：每项同时给出infrastructure结果及notification_delivery是否实际observed。以条件确认后的计数差值condition_callbacks判定，不把锁屏前或断网恢复后的回调算入条件内；没有测量区间的阶段记Not assessed。没有可控真实通知发送端时，零回调记Not exercised，绝不伪造Alipay来源、放宽签名、调用夹具代替或把零计数算通知通过。instrumentation会影响进程优先级，因此锁屏/Doze测试不是自然LMK回收或量产后台可靠性证明；进程故障单独由宿主触发。
- AUTO-06：宿主所有命令、阶段均有超时，逐阶段保存仅含固定状态/计数的私有JSON及测试日志；异常也进入清理。清理失败明确报告，不隐瞒未恢复设置。重启保留userdata/KeyStore/账本，先后独立audit确认四笔合成账务不变。不触发聊天、转账、付款或正文采样。

重启须确认boot_id变化且sys.boot_completed=1，容忍设备切换期离线；boot_id仅在进程内比较，不输出到报告。诊断后可用`--stages`只补跑受影响阶段，报告列出本次计划项；缺失阶段不可补记通过。实时日志仅解析完整结构化行，避免读取一半的ready行触发错误故障。

网络状态使用shell侧`dumpsys connectivity`的单行`Active default network`元数据，不读取网络地址或业务流量；无INTERNET权限探针的UID视角不能代替系统默认网络。只验证默认网络断开/恢复，不据此宣称平台服务器连接或积压通知成功恢复。

条件等待按约每秒采样复核熄屏/keyguard、离线默认路由或强制Doze；结束采样通过后才取计数差值。采样不能证明两个检查点之间无短暂变化；记录minimum_seconds及实际elapsed_ms，不能把shell检查耗时写成精确15秒。每次fresh使用独立阶段名和排他创建日志，禁止覆盖先前证据。audit前后均须匹配四笔/总增额30,000,000的固定基线，仅相等不足以通过。网络单行过滤由测试端通过UiAutomation的sh标准输入执行（API31+），不把管道字符直接传给dumpsys。

## 用户配合的单次普通消息窗口

2026-10-17用户明确同意收到提示后自行发送普通支付宝消息。PROBE-04的新增驱动仅放在androidTest：原探针按钮开启120秒窗口，探针在前台、支付宝在后台，保持屏幕亮起且keyguard未锁定。先通过固定来源校验、既有监听授权及连接，输出零计数的armed状态后才提示用户发送1条消息。代理不代发消息，不操作支付宝业务，不读取弹窗、通知正文或其他App界面。

- LIVE-01：测试运行期间只输出固定来源匹配、连接、窗口状态、聚合计数、elapsedRealtime差值、屏幕交互和keyguard布尔值；不使用运行中的UI层级读取、截图、活动通知枚举或通知服务内容dump，以免顺带读取聊天弹窗正文。主APK及120秒上限不改动。
- LIVE-02：用户发送时间与实际发送次数单独记录为用户反馈；窗口起点计数必须为0，结束时记录完整窗口差值。有回调只记Observed，不能推导独立消息/付款笔数或归属；没有回调记Not exercised，不把已触发但零回调写成通过。宿主记录到“已发”的时间不等于发送时刻；确认落在窗口外且没有独立发送时间时，标发送与窗口关系未确认，不能判断实际漏投。对外提示同时给出UTC截止时间；不因为确认来晚而自动重复要求发消息，也不自动连续重开窗口绕过120秒上限。
- LIVE-03：前台测试窗口的keep-screen-on仅作用于测试Activity并随Activity结束解除，不改系统屏幕超时、锁屏策略、网络、支付宝通知权限或监听授权。异常也停止窗口并结束测试Activity；宿主超时后显式停止探针，并独立审计原四笔账务。instrumentation的进程优先级影响及模拟器证据边界仍保留。
