# SPEC-019 本地事件状态与可预览诊断

2026-10-16；#24，承接SPEC-017/018与用户流程。本地只读状态/导出与SPEC-020独立认证健康检查共同验收；检查不得伪造事件，全部测试完成前不声明#24交付。

## 状态

显示最近20个持久候选的短event_id、provider、金额、观察时间、本地身份/发送状态及明确暂停原因。查询只取所需列，不加载body/payload/密钥。排序按observed_at及event_id稳定排序。历史UNBOUND、IDENTITY_CONFLICT、READY/RETRY/IN_FLIGHT、ACKED、HELD/TERMINAL分别显示；未知枚举用固定“未知状态”标签，不能输出任意数据库文本。

ACKED只称“网关已接收”；网关记账/商户通知/充值状态在没有对应查询证据时显示“未查询”，不得将accepted、credited、merchant_notified混为成功。最近ACK时间延续SPEC-018；本地事件时间不当作平台付款时间。

## 诊断与导出

用户点击后才生成预览，预览后选择导出再打开Android系统文档保存界面。无自动导出、后台发送、剪贴板复制或共享外部App。取消预览/文件选择不创建报告文件，不改变事件/重试/授权状态。异步读取/写入，不阻塞通知采集或主线程。

诊断schema_version=1仅允许固定字段：应用版本/API级别/测试或正式模式、通知权限与监听状态、各渠道本地绑定是否存在、持久身份/候选/冲突总数、保存缺口/容量告警、固定队列状态的数量、是否已有持久ACK。未知队列状态仅汇总OTHER，不将原字符串作为JSON键。禁止通知原文、金额、事件/订单/设备/receiver/key标识、网关地址、密钥/签名/凭据、付款人、异常堆栈或设备型号。预览显示本次将保存的精确JSON，导出使用同一冻结字符串。

导出通过ACTION_CREATE_DOCUMENT、application/json和用户选择的content URI写入；不申请存储权限，不添加公开FileProvider，不向网络发送数据。失败仅显示固定错误，不记录原异常或URI。最终报告样例使用合成汇总。

## 验收

- STATUS-01：本地绑定/权限/监听/发送/ACK/业务状态分开；全部发送状态和未知枚举映射可测试。
- DIAG-01：严格字段白名单，恶意/未知状态字符串及注入的标识/原始内容不进入汇总JSON。
- DIAG-02：必须预览后才进入文件选择；取消不导出；实际用户选择的文件与预览字节一致。
- DIAG-03：空队列与持久事件页面、错误原因及测试模式截图，禁止渲染测试grant/密钥。
- DIAG-04：构建/JVM/AVD/lint/APK隔离；不新增危险权限/公开组件，不使持久事件重绑定。
