# SPEC-031 一次性私有支付宝通知内容采样

2026-10-18；#73，承接#33。用户明确允许一次120秒采样、读取标题和正文（可能含普通消息），仅本机私有保存，提取脱敏模板后删除原文。既有通知可达、配对和生命周期证据直接复用。本批不改变网关协议或生产采集准入。

## 约束

- 独立debug-only `sample` 模块，无网络权限、上传、配对、事件或账本依赖；不修改SPEC-028的无正文/存储探针，不改production来源、解析或上报开关。
- 固定支付宝包、versionCode 212310及D0签名集合，与SPEC-028完全相同；package/opPkg/Android用户/UID/版本/签名先核验，失配停止。其他包忽略。仅处理窗口内onNotificationPosted，不枚举活动/延后通知，不读取聊天页、账号页、截图、UI dump或通知服务正文dump。
- 仅读取Notification.EXTRA_TITLE和EXTRA_TEXT，分别最多256/1024个UTF-16单元，不读取其他extras或通知key/id/tag/channel/postTime。内容supplier只能在同步窗口gate中、来源确认及elapsedRealtime截止检查后调用；每字段取值前重查截止，超时后不再访问字段。更新/重投可能重复计数，不据样本数认定独立通知/付款数。
- 一次120秒，开始时同步写入no_backup永久used标记；进程重启、断连、停止、时间倒退、来源失配、存储异常默认停止，不续窗、不清数据重置。最多32条，达到上限停止；只有显式本地androidTest许可可启动，外部Intent与状态UI不能启动。
- 原文仅应用私有no_backup文件及宿主0700目录/0600文件，禁备份、外部存储、日志和stdout回显。UI只有固定状态和停止。宿主stdout直接重定向私有文件，不经模型；长度/条数有上限。宿主默认遮蔽全部未知文本及数字，只保留公开固定词和有限标点，模板仍仅私有保存。普通聊天可能含收款词，不能据此宣布真实收款。
- 结束或失败均先停止/强停采样，撤销其临时监听权限，再取回/脱敏并删除设备与宿主原文；失败不自动重跑窗口。保留used标记及无正文元数据；清理失败必须报告。文件删除是逻辑删除，不声称介质安全擦除。主客户端原权限不变，不启动新AVD、不清应用数据、不发消息/付款。
- instrumentation影响优先级，本批不验后台自然回收。没有受控触发端时被动观察，零样本记Not exercised，不要求用户重复发普通消息。原隔离四笔/总增额30,000,000前后审计不变；不接入网关或真实充值。
