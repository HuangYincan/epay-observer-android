## #59 人工配对前的AVD时钟预检

2026-10-16人工验收发现AVD时钟落后约433秒。设备请求的5分钟偏差和配对not_before最多等待5秒的既有约束保持不变。辅助脚本在正常TLS管理员登录后、创建grant之前，读取受信任响应的Date和显式模拟器当前UTC，允许最多3秒的近似偏差（包含Date/date秒级精度）；超过阈值、缺失/非法Date、ADB不可用时停止，不创建新grant。

只接受emulator-NNNN目标（默认本机emulator-5554，可显式--serial），不能对真机自动执行。时钟预检不设置设备时间、不扩大服务器窗口、不自动延长grant或兑换凭据。检测到问题先恢复正确系统时间，重新预检后才开始新的5分钟授权；已兑换但未激活的过期绑定按SPEC-016正常撤销/替换，不清事件/账务。
